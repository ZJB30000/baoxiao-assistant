# 报销智能助手（baoxiao-assistant）

> FDE 工程技术与创新实践 · 课程作业项目

## 一、项目简介

在日常报销流程中，行政专员**乔姐**需要反复向员工解释报销制度，财务专员**周敏**需要反复被员工查询单据审核进度，浪费了大量重复劳动。本项目的工程师**陈工**设计并落地了"报销智能助手"，将这两类高频问题交给员工自助解决：

- 员工自助查询现行有效的报销制度（全员可见，无需求助乔姐）；
- 员工经授权后自助查询**本人**单据的审核状态（无需反复打扰周敏）。

本项目为**纯前端 MVP 版本**，无后端、无数据库，使用 `localStorage` 持久化数据，双击 `index.html` 即可在浏览器中运行。

## 二、核心需求（分两层实现）

| 层级 | 功能 | 面向用户 |
| ---- | ---- | -------- |
| 第一层（基础 · MVP） | 报销制度列表 + 关键词搜索 | 全员可见 |
| 第二层（扩展功能） | 工号 + 验证码查询本人单据审核状态 | 经授权的本人 |

## 三、关键设计原则

1. **渐进式开发**：先完成第一层制度查询（MVP 可用），再扩展第二层单据状态查询。
2. **权限最小化**：单据查询必须经授权（验证码），且严格"本人查本人"——工号、姓名、验证码三者全部匹配才能查询，防止越权查看他人单据。
3. **职责分离**：制度内容由乔姐在管理页维护（可新增 / 编辑 / 删除）；单据数据由周敏核对录入（本版本使用模拟数据）；保留人工把关，系统不是完全自动化。

## 四、功能说明

### 1. 制度查询（主页 `index.html`）
- 展示全部现行有效报销制度（分类、标题、生效日期、正文）；
- 支持关键词搜索（标题 / 分类 / 正文），支持回车搜索与一键重置。

### 2. 单据查询（查询页 `query.html`）
- 输入**员工工号 + 姓名 + 查询验证码**完成身份核验；
- 核验通过后仅显示**本人**单据的审核状态（单据编号、类型、金额、提交日期、状态、备注）；
- 任何一项不匹配都拒绝查询，无法查看他人数据。

### 3. 制度管理（管理页 `admin.html`）
- 管理密码登录后，乔姐可**新增 / 编辑 / 删除 / 恢复默认**制度；
- 修改保存后，主页全员立即可见最新制度。

## 五、使用方法

```bash
# 1. 克隆仓库
git clone https://github.com/你的用户名/baoxiao-assistant.git
cd baoxiao-assistant

# 2. 直接双击 index.html 即可在本机浏览器打开使用
open index.html
```

> 也可将仓储打包下载，在浏览器中打开 `index.html` 使用。无需安装任何依赖。

| E004     | 赵六 | 9753       |

- 管理页初始密码：`123456`（演示用，可在 `js/data.js` 中修改）
- 单据数据为**模拟数据**，由财务专员周敏核对录入，可在 `js/data.js` 中维护

### 数据说明

- 所有数据保存在浏览器 `localStorage` 中（不会上传到服务器）；
- 管理页提供"恢复默认制度 / 恢复全部默认数据"功能，可随时还原演示数据；
- 如需清空数据：浏览器开发者工具 → Application → Local Storage → 删除 `baoxiao-rules` 与 `baoxiao-employees` 即可。

## 六、技术栈

| 技术 | 说明 |
| ---- | ---- |
| HTML5 | 页面结构（三个页面：主页 / 查询页 / 管理页） |
| CSS3 | 全站统一样式，响应式布局 |
| JavaScript（原生 ES5） | 页面逻辑、数据校验、搜索过滤 |
| localStorage | 数据持久化（制度数据 + 模拟单据数据） |
| GitHub Pages | 可选：发布后全员可通过网址访问 |
